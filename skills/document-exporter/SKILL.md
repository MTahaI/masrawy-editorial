# document-exporter

نفّذ:
`python C:/Users/m122s/.config/opencode/skills/document_exporter.py "{{title}}" "{{filename}}" "{{format}}" "{{content_path}}" ["{{output_dir}}"]`

- `title`: عنوان التقرير بين علامتي تنصيص.
- `filename`: اسم الملف الناتج بدون امتداد.
- `format`: `docx` (Word) أو `pdf` أو `both` (الملفان معًا).
- `content_path`: مسار ملف نصي (.txt) بترميز UTF-8 يحتوي نص التقرير. قبل الاستدعاء احفظ النص كاملًا في ملف مؤقت ثم مرّر مساره.
- `output_dir` (اختياري): مجلد الإخراج — الافتراضي: سطح المكتب.
- الترويسة تُضاف تلقائيًا: «مصراوي — تقرير استراتيجي» مع خط فاصل.
- عناوين Markdown داخل المحتوى (`#` و`##`) تتحول إلى عناوين فرعية في الملف الناتج.
- مسار/مسارا الملفات الناتجة تُعرض على المستخدم كما وردت دون تحوير.

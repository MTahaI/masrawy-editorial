# trend-radar

نفّذ: `python C:/Users/m122s/.config/opencode/skills/trend_radar.py "{{platform}}"`

المعامل `platform` كلمة واحدة فقط: `masrawy` (رادار الشارع المصري) أو `weaam` (رادار الشارع السعودي).

الرادار يسحب أعلى 7 تريندات لحظية عبر Google Trends (محرك البحث هو «المرآة الصادقة» لفضول الشارع — لا يعتمد على واجهات إكس/فيسبوك المغلقة).

النتيجة تُعاد كما وردت دون تحوير، وتتضمن أوامر اقتناص الفرصة. تُعرض على رئيس التحرير لاتخاذ قرار التقاط التريند قبل أي كتابة.

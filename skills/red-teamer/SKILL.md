# red-teamer

نفّذ: `python C:/Users/m122s/.config/opencode/skills/red_teamer.py "{{raw_file}}" "{{draft_file}}"`

- `raw_file`: مسار ملف نصي (UTF-8) يحتوي النص الخام/المصدر (الحقيقة المطلقة).
- `draft_file`: مسار ملف نصي (UTF-8) يحتوي مسودة الخبر المراد تفتيشها.
- قبل الاستدعاء احفظ النصين في ملفين مؤقتين ثم مرّر مساريهما.

الوكيل يقارن بصرامة عبر Gemini (`gemini-3.5-flash` عبر المكتبة الرسمية `google.genai`) ويُخرج تقريرًا تحذيريًا بالثغرات (أرقام، أسماء، اقتباسات محرفة)، أو عبارة «✅ الفحص المضاد سليم» عند المطابقة الكاملة.

النتيجة تُعرض على رئيس التحرير دون تحوير، ولا تُنشر المسودة قبل اجتياز الفحص.

**حالة الإعداد:** مفتاح Gemini API مُدخل في `red_teamer.py`، والمكتبة الحديثة `google.genai` مثبتة.
